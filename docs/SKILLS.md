# 技能说明文档

本项目的核心是 5 个 Skill，每个都有明确的职责边界。

---

## 1. learning-agent（Supervisor 主管）

**定位**：整个系统的大脑。

| 属性 | 内容 |
|---|---|
| 角色 | 拆解任务、分派给子 Agent 或工具、汇总结果 |
| 权限 | Read + Write |
| 触发器 | 任何与学习相关的问题 |
| 依赖 | references/preferences.md（用户偏好） |

**工作方式**：ReAct 循环

```
Thought → 拆任务：自己干还是派出去？
Action → 调工具 或 调子 Agent
Observation → 拿回结果
循环 → 信息足够时输出 Answer
```

**调度规则**：
- 联网搜索 → 派 `search-agent`
- 格式化写作 → 派 `writing-agent`
- 数据提取 / 分析 → 自己调 `study-stats` / `study-review`

---

## 2. search-agent（联网搜索）

**定位**：只做一件事——联网搜索并返回结构化结果。

| 属性 | 内容 |
|---|---|
| 角色 | 搜索 |
| 权限 | web（仅此一个） |
| 调用方式 | 被 Supervisor 通过 `run_skill` 调用 |
| 不做 | 不分析数据、不写报告、不做总结 |

**入参**：
```
任务：<搜索关键词>
数据：（空）
格式要求：中文优先
```

**出参**：
```
[状态] 成功 / 无结果
[数据] <搜索结果，标题+来源+摘要>
```

---

## 3. study-stats（数据提取）

**定位**：从学习笔记中提取统计数据。

| 属性 | 内容 |
|---|---|
| 角色 | 读笔记 → 提取完成事项、时长、完成率 |
| 权限 | Read + Write |
| 去脚本化 | 不依赖 Python 脚本，AI 直接读取并统计 |

**输出**：
```
- 日期
- 学习时长
- 完成事项数 / 未完成事项数 / 完成率
- 已完成事项清单 / 未完成事项清单
```

---

## 4. study-review（复盘分析）

**定位**：生成结构化复盘报告。

| 属性 | 内容 |
|---|---|
| 角色 | 根据 stats 数据 + 复盘模板，生成四个维度的复盘 |
| 权限 | Read + Write |
| 输出 | 时间回顾 / 内容回顾 / 问题诊断 / 明日调整 |

**三分支**：
- 完整复盘 → 调用 stats → 按模板输出 → 追加到笔记
- 查单日数据 → 只返回 stats 数据
- 多天对比 → 返回多天数据表格，交由调用方分析

---

## 5. writing-agent（格式化写作）

**定位**：把原始数据整理成结构化书面内容。

| 属性 | 内容 |
|---|---|
| 角色 | 写作排版 |
| 权限 | Read + Write |
| 调用方式 | 被 Supervisor 通过 `run_skill` 调用 |
| 不做 | 不搜索、不统计数据、不做分析判断 |

**入参**：
```
任务：周报 / 笔记 / 对比报告
数据：<原始内容>
格式要求：中文优先
```

**出参**：
```
[状态] 成功 / 错误
[数据] <格式化后的完整内容>
```

**支持三种格式模板**：
1. **周报式** — 概览 + 逐日明细 + 本周重点
2. **笔记式** — 主题 + 学到的东西 + 关键洞察 + 下一步
3. **对比报告式** — 对比表格 + 变化分析

---

## 设计模式总结

| Skill | 类型 | 调用方 | 职责 |
|---|---|---|---|
| learning-agent | Supervisor | 用户 | 拆任务 + 派活 + 汇总 |
| search-agent | 子 Agent | Supervisor | 搜索 |
| study-stats | 工具 | Supervisor / study-review | 数据提取 |
| study-review | 工具 | Supervisor | 复盘分析 |
| writing-agent | 子 Agent | Supervisor | 写作 |
