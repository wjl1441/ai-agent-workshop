Git 初始化到推送 GitHub 指令总结

━━━━━━━━━━━━━━━━━━━━━━━━

1. 配置 Git 身份（第一次使用 Git 必做）
   指令：git config --global user.email "你的GitHub邮箱"
         git config --global user.name "你的GitHub用户名"
   目的：告诉 Git 你是谁，每次提交会记录这个身份

2. 初始化本地仓库
   指令：git init
   目的：在当前目录创建一个 Git 仓库，开始版本管理

3. 添加文件到暂存区
   指令：git add .
   目的：把当前目录所有文件标记为"待提交"

4. 提交文件
   指令：git commit -m "提交说明"
   目的：把暂存区的文件正式保存为一个版本

5. 解决 SSL 证书验证失败（Windows 常见问题）
   指令：git config http.sslverify false
   目的：临时关闭 SSL 证书验证，绕过"unable to get local issuer certificate"错误

6. 关联远程 GitHub 仓库
   指令：git remote add origin https://github.com/你的用户名/仓库名.git
   目的：告诉本地仓库，远程仓库在哪里

7. 推送到 GitHub
   指令：git push -u origin master
   目的：把本地代码推送到 GitHub，-u 让后续只需 git push 即可

━━━━━━━━━━━━━━━━━━━━━━━━

常用组合（后续修改代码后推送）：
   git add .
   git commit -m "更新说明"
   git push
