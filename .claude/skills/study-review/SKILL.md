# 每日学习复盘助手

## 职责

根据用户意图判断走哪个分支：完整复盘 / 查单日数据 / 多天对比。

## 工作流程

根据用户问题中的关键词选择分支：

### 分支A：完整复盘（关键词：复盘 / 今日总结 / 回顾今天）
1. **获取数据** — 调用 `run_skill("study-stats")` 获取今日学习统计数据
2. **按模板组织内容** — 按 `references/review-template.md` 的四个维度（时间回顾、内容回顾、问题诊断、明日调整）填写判断性内容
3. **记录** — 将完整的复盘报告追加到今日笔记

### 分支B：查单日数据（关键词：查数据 / 某天 / 某日）
1. **获取数据** — 调用 `run_skill("study-stats")` 获取指定日期的统计数据
2. **直接返回** — 输出原始统计数据，不做定性分析

### 分支C：多天对比（关键词：对比 / 比较 / 对比两周）
1. **获取多天数据** — 多次调用 `run_skill("study-stats")`，每次指定不同日期范围
2. **返回原始数据** — 将各天的统计数据以表格形式返回，不做分析结论，交由调用方自行分析

## 复盘框架

严格遵循 `references/review-template.md` 中的复盘模板来组织输出。

## 输出格式

### 分支A（完整复盘）输出：
- 今日学习时长统计
- 各科目时间占比
- 完成事项清单
- 未完成事项
- 薄弱知识点
- 明日改进建议

### 分支B（查数据）输出：
- 日期 / 学习时长 / 完成项数 / 未完成项数 / 完成率
- 不生成分析性内容

### 分支C（对比）输出：
- 各天的原始统计数据（表格）
- 不做分析结论
