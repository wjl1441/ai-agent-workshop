|      |          |          |               |

- 遇到的卡点：n
- 错题类型分布：
- 是"不会"还是"不熟"？（概念不清 vs 练习不够）

### 4. 明日调整
- 需要重学的知识点：
- 需要加练的题型：
- 学习节奏调整建议：

## 复盘的黄金法则

> 复盘不是记流水账，而是找到"今天如果重来一次，我会在哪里做得不一样"的答案。
