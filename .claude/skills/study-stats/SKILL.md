# 学习数据统计

## 职责

从每日学习笔记中提取结构化统计数据，不做定性分析。

## 工作流程

1. **读取笔记** — 读取用户的每日学习笔记文件
2. **手动提取数据** — 从笔记内容中找出：
   - 从 `- [x]` 行统计**已完成事项**
   - 从 `- [ ]` 行统计**未完成事项**
   - 从正文中寻找学习时长记录
   - 从标题或日期行确定日期
3. **返回数据** — 输出结构化统计结果，不添加分析结论

## 输出格式

输出应包含以下信息：
- 日期
- 学习时长（小时和分钟）
- 完成事项数
- 未完成事项数
- 完成率
- 已完成事项清单
- 未完成事项清单
